Why this exists

One radar instead of five group chats.

AI and Product events in India don't live in one place — they're scattered across NASSCOM mailers, conference-organizer newsletters, X threads, and WhatsApp forwards, usually surfacing after registration's already tight. This page checks the usual places every morning, pulls out what's actually happening, and drops it here — so finding out means scrolling once, not five different apps.

How it works

The actual pipeline behind the signal.

No manual curation — a script does this every day, unattended.

1

Search

Tavily runs ~35 targeted searches daily — AI and Product topics, by city, keyword, and format.

2

Extract

Gemini reads the results and pulls structured events — name, date, city, category. Groq steps in automatically if Gemini's quota runs dry.

3

Track

New events land in the database, duplicates get skipped by URL, and statuses refresh daily at 07:00 IST via GitHub Actions.
